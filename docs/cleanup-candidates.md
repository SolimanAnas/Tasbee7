# Cleanup candidates

Files that look redundant, unused or not part of the app, found during the October 2026 audit.
**Nothing here has been deleted.** Review each item and remove or move it yourself.

How this list was made: every tracked file's name was searched for in all HTML, JS, CSS and JSON
(including `sw.js` and `manifest.json`), and scripts and styles were checked for an actual
`<script src>` / `<link href>` / `import` from a page. Files whose names are built in code
(numbered pages, `page_${n}.webp`, `audio-${n}.json`, video thumbnails) were treated as used.

When you remove a page or file, also remove it from the precache lists in `sw.js` and bump
`CACHE_NAME`, otherwise `scripts/verify-precache.cjs` fails in CI.

`mushaf pages/…` and `mushaf-2/`, so keep those two.
